# 家教入驻系统 · 手工验收清单

> 后端单元/集成测试（15 个）与 E2E 冒烟已自动化通过（见 feature/tutor-onboarding 分支各任务提交）。
> 本清单覆盖无法自动化的部分：真机 UI、微信登录、上传交互、状态流转的全流程体验。

## 准备
1. `cd backend && go run .`（端口 8080）
2. 微信开发者工具打开 `miniprogram/`，详情设置勾选「不校验合法域名」
3. 管理员提权（先在「我的」tab 登录一次，然后；`<code>` 为登录用的任意字符串）:
   sqlite3 backend/database/tutors.db "UPDATE users SET role='admin' WHERE openid='dev_openid_<code>'"
   提权后重新进小程序触发一次登录获取新 token（role 写在 JWT 里）

## 验收路径
- [ ] 「我的」tab 显示，图标正常，登录后为未入驻状态卡
- [ ] 申请入驻 → 四步表单：必填校验逐字段报红（空姓名/未选性别/时薪 10/短简介分别触发）
- [ ] 科目分组：学科/素质与课外两组可选（钢琴、编程等）；自定义科目「古筝」可添加为标签并删除；>8 个或 >12 字被拦截
- [ ] 步骤三上传凭证：选图 → 上传中 loading → 缩略图出现；可删除；gif 改名 .png 上传被拒（内容嗅探）；>5MB 被拒
- [ ] 上传中连点「＋」不会并发上传（重入拦截）
- [ ] 简介稿纸格显示格线与字数统计
- [ ] 提交成功 toast「已存入公报」→ 回「我的」显示「审核中」
- [ ] 提交后 800ms 内连点/返回：无重复提交、无错误页面弹出
- [ ] 家长端（首页/名录）此时**看不到**该家教
- [ ] 管理员登录 → 「我的」出现编辑部入口（待审 1 件）→ 审核页可见申请详情与凭证图
- [ ] 凭证图点击可全屏预览（previewImage）
- [ ] 不填原因驳回 → toast 拦截；填原因驳回 → 成功
- [ ] 家教端「我的」显示「已驳回 + 原因」→ 重新提交 → 回「审核中」
- [ ] 管理员通过 → 家长端首页/名录**能看到**该家教，详情正常，联系功能返回微信号
- [ ] 已通过档案再编辑提交 → 状态回「审核中」且家长端仍可见（编辑即时生效语义）
- [ ] 弱网模拟（开发者工具 Network → Slow 3G）：「我的」refresh 失败 → 显示「调阅失败/重新调阅」而非「未入驻」卡
- [ ] JWT 过期模拟（改系统时间或等 72h，或手动清 storage 后重进）：静默重登，无死循环
- [ ] 断网提交 → 错误 toast，表单内容不丢
- [ ] 四个页面（mine/apply/admin-audit/列表）的加载/空/错误/成功态符合「成绩单公报」设计语言（纸底/墨绿/印章红）

## 已知限制（验收时不算缺陷）
- 凭证图 URL 为永久无鉴权（UUID 不可枚举缓解）——规格 §9 既定风险模型，OSS 签名 URL 属后续阶段
- 待审 >50 件需翻页（当前无加载更多）
- 安卓端宋体标题退化为默认黑体（系统字体限制）
