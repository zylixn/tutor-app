## 3.1 评审方差说明

单次评审波动 ±0.75（R3 三次独立评分 6 / 7 / 5.5）。R1–R2 为单评审样本；R4 采用三评审中位数。各轮评审想象的"工作室标准"存在漂移（R3 乙要求纸纹颗粒、印泥残边等 WXSS 无法实现的物料级质感），横向比较时应以中位数为准。

### R2 → R3 已处理项

- **全站命名词典**：列表页导航=「本期目录」/首页报头=「家教公报」/名录页=「教师名录」/详情=「教师档案」；占位文案统一「检索科目、年级、地点…」；认证徽章全站唯一写法「认证」
- **空块头像清除**：预览照片位改人像剪影（应用内照片必有图，无图走篆印）
- **详情头部**：四连 chip → 铅字小传（`所在地/年级` label-value 两栏对齐），【】仅保留给科目
- **行情数字规范**：全局唯一数字规格——衬线 900 墨绿 + tnum，单位/标签小一号降灰；列表/统计带/评价三处统一
- **筛选抽屉**：加公报式报头「筛选 + 已选 N 项」（WXML 表达式计数，无 JS 变更）+ 价格行内嵌「元/时」
- **骨架屏**：灰块 → 「排字中」行线占位（长短交替细线 + 空框）
- **星级**：大居中五星 → 行内 ★ 与等第文案同行左对齐
- **色彩语义**：错误态主体用墨色，印章红只留给「重新检索」动作
- **检索行筛选**：描边按钮 → 文字动作 + 激活时印章红点
- **详情落款**：评价区末尾加「本档案核验于 NO.xxxx · 家教公报」folio
- **空/错误态**：纳入「启事」栏目编排（栏目眉 + 规线 + 铅字按钮）
- **shot-e 交付**：四帧完整不裁切（窗口 440×1900）

### R1 → R2 已处理项

- **卡片堆 → 连续纸面**：列表条目/详情分区/筛选面板全部去掉边框盒，改发丝线分隔 + 通栏统计带；筛选改底部抽屉 + 遮罩（`onToggleFilter` 复用，无 JS 变更）
- **字阶纪律**：建立四级字阶令牌（`--fs-display/name/body/sub/label`），价格专属衬线处理（宋体 900 墨绿），数字等宽
- **详情页节奏**：科目【】/年级并入头部元信息，六卡 → 四个发丝线分区，章序号删除（信息设计优先）
- **状态页**：loading 改骨架屏（与条目同几何）、错误文案统一公报语气（「检索失败」）、成功态改红印「已收录」仪式
- **标签分类学**：科目=铅字直角【数学】无边框、资质=印章红描边、元信息=纯文本+标签框
- **列表统计行**：三栏仪表盘 → 一行排印「评分 4.9 · 时薪 180元/时 · 教龄 5 年」，时薪衬线绿字
- **头像**：无照片时改单字篆印（白文印），照片加档案照双线框
- **对比度**：`--ink-soft`/`--ink-faint` 加深至 AA（≥4.5:1）
- **触控目标**：筛选按钮/选项/星级提升至 ≥64rpx（36px）
- 预览假差距修正：预览图补仿真原生导航条；shot-e 状态合集改四台迷你整机（删除暴露交付物的英文标签）
