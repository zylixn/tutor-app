# 设计简报：家教小程序 · 成绩单公报

> 品味批注已由 PM 于 2026-11-22 通过四项决策确认（宋体范围 / 印章红剂量 / 公报横条 / 纸色）。

## 1. 基本信息

| 字段 | 内容 |
| --- | --- |
| 产品与页面 | 家教小程序（Go + 微信原生小程序）· 全部 4 页 + tutor-card / filter-panel 组件 + 导航/标签栏 |
| 目标受众 | 家长（30–50 岁），晚间与碎片时间刷列表，信任敏感：看重学历、认证、价格、评价 |
| 核心任务 | 快速浏览并筛出"靠谱、价格合适"的家教，进入详情联系 |
| 主行动 | ① 搜索/筛选家教 ② 查看详情 ③ 联系家教 |
| 交付范围 | 4 页面 WXML/WXSS + 2 组件 + app.json 导航/标签栏 + 标签栏图标重绘；无动效素材（小程序端以静态排版为主）；评审用 HTML 镜像 + 截图 |

## 3. 品味批注（PM 已确认）

| 句式 | 内容 |
| --- | --- |
| 我想象的感觉 | 翻开一份纸质公报：安静、可信、有编号的秩序感；姓名是宋体的，价格是打字机等宽的，分隔靠表格线而非阴影 |
| 明确避免 | 默认蓝、彩色渐变、胶囊圆角、投影卡片、Ant 风格填充色标签、全局紫蓝渐变等一切"模板味"；**印章红不得扩散到认证之外**（错误提示除外） |
| 取而代之 | 标题宋体 + 正文黑体；单色墨绿层级；hairline 表格线分区；标签用描边而非填充；期号横条保留在首页顶部 |
| 还缺什么 | 底色定为米白 `#F7F4EC`；标签栏图标需按新配色重绘（现有为默认蓝）；安卓宋体退化为黑体视为可接受 |

## 4. 约束

| 类型 | 内容 |
| --- | --- |
| 功能约束 | 仍须作为家教列表/详情工具工作：搜索、筛选、列表、详情、写评论全部可用；不改任何 JS 逻辑与数据流 |
| 品牌约束 | 无既有品牌色（现默认蓝即为"避免"对象）；印章红仅限认证徽章 + 错误态 |
| 技术约束 | 微信原生小程序（WXML/WXSS/rpx）；不引入外部字体文件（系统字体栈：宋体 `Songti SC/STSong/Noto Serif SC/SimSun`，等宽 `Menlo/SF Mono/Consolas`）；标签栏图标需本地 PNG 重绘 |
| 可访问性 | 正文对比度 ≥ 4.5:1（#22302B/#F7F4EC ≈ 12:1，墨绿 #175243 在米白上 ≈ 7.8:1）；触控目标 ≥ 44px；不依赖颜色单独传达信息（认证同时有文字） |
