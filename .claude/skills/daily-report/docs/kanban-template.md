# 通用看板模板

> **用途**：新建战役看板时复制本文件，替换所有 `{占位符}`。
> **约束**：填充必须严格遵守 `kanban-format.md`（与本文件同目录），违反即 P0 否决。
> **来源**：从 `630_kanban-LOCKED.md`（v3.3 LOCKED）抽取，去业务化后形成通用骨架。

## 使用步骤

1. 复制本文件到 `reports/<YYYY>/knowledge/<战役>_kanban.md`（如 `730_kanban.md`）
2. 全文替换占位符（`{...}` 包裹的字段）
3. 按需扩展/收缩 Sprint 数量（最少 1 个，建议 3-4 个）
4. 按需扩展/收缩主线分组（参考 CLAUDE.md §0.5 前缀表）
5. 填充任务行时严格遵守 `kanban-format.md` 的列规范、状态枚举、编号规则
6. 核算 4 张统计表自洽（总数、状态分布、人员加总、工作域加总）
7. 提交 PM 审批 → 批准后追加 `LOCKED` 标记
