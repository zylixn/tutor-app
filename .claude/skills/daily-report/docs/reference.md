# Daily Report 模板参考

> 从 SKILL.md 提取的日报模板和看板展示模板。主文件链接至此。

## 日报必填章节模板

```markdown
# 个人日报 - {YYYY-MM-DD}

## 基本信息
| 项目 | 内容 |
|------|------|
| 作者 | {git_user} |
| 角色 | {角色} |
| 仓库 | {项目名} |
| 报告日期 | {YYYY-MM-DD} |

## 今日工作完成情况
### 已完成任务 ✅

按标签分组展示，每条任务格式：`**{n}.【标签】{任务标题}** — Commit: {hash}`

#### 标签分组规则

根据 commit message 关键词自动归类：

| 标签 | 匹配关键词 | 适用范围 |
|------|-----------|---------|
| 框架升级 | 版本、升级、upgrade、version | 框架版本管理、依赖升级 |
| 安全加固 | 安全、加固、GATE_BYPASS、NONCE、权限、拦截 | 安全相关修复和加固 |
| 质量工具 | TDD、测试、hook、覆盖率、检查 | 质量门禁和自动化工具 |
| Skill 方法论 | skill、CSO、R1-R4、writing-skills、方法论 | 技能体系建设和优化 |
| Agent 行为 | Agent、角色、行为、Iron Law、Developer/Tester/Reviewer | 多智能体行为定义 |
| Bug 修复 | BUG、修复、fix、兼容 | 缺陷修复 |
| 规范 | 规范、commit、格式、命名、文档 | 流程规范和文档 |
| 功能开发 | DEV、新增、实现、feature | 新功能开发 |
| 重构 | CM、重构、refactor、拆分、优化 | 代码重构和优化 |
| 验证 | 验证、测试、对抗 | 验证性工作（无新提交） |

**输出格式**：

```markdown
**1.【{标签}】{任务标题}** — Commit: {hash}
- {关键成果描述}
- Commit: {hash2}（如有多个相关提交）

**2.【{标签}】{任务标题}** — Commit: {hash}
- {关键成果描述}
```

> 分组规则：同一标签下按时间顺序排列；不同标签按首次出现顺序排列；验证性工作归入对应标签。标签超过 5 个时合并相近标签。

### 进行中任务 ⚠️
| 任务 | 进展 | 预计完成 |
|------|------|----------|

### 工作量统计
| 指标 | 数值 |
|------|------|
| 提交数 | {n} |
| 变更文件数 | {n} |
| 新增行数 | +{n} |
| 删除行数 | -{n} |

## 提交协作分析
| 分类 | 提交数 | 占比 | 提交列表 |
|------|--------|------|----------|
| 🤖 AI 独立完成 | {n} | {pct}% | {hash摘要列表} |
| 🤝 AI 协作提交 | {n} | {pct}% | {hash摘要列表} |
| 👤 人工独立提交 | {n} | {pct}% | {hash摘要列表} |

> **分类依据**：commit 首行末尾 `[...]` 中的操作者类型标识

## 规划对照分析（基于个人看板）
| 看板编号 | 任务 | 计划 Deadline | 今日状态 | 进展说明 |
|----------|------|--------------|---------|---------|
| K-03 | API 网关重构 | 5/20 | ✅ | 核心模块开发完成 |
完成率: {n}/{n}（{percentage}%）

> 数据来源：当月整体看板自动筛选，无看板数据时标注"看板数据不可用"

---

## 风险与阻塞
| 风险项 | 影响域 | 程度 | 状态 |
|--------|--------|------|------|
```


#### 状态标识
- ✅ 已完成
- ⚠️ 进行中/有风险
- ❌ 未完成/阻塞
- 🟢 超前
- 🟡 轻微滞后
- 🔴 严重滞后

## 团队整体看板展示模板

```markdown
## 📋 团队看板

> 数据来源：{看板文件名}，最后更新：{看板末尾标注的更新日期}

| 紧急度 | 任务 | 责任人 | Deadline | 状态 |
|--------|------|--------|----------|------|
| 🔴 | PA-01 Schema 迁移框架 | ZCW | 5/8 | 🔵 |
| 🔴 | S0-03 CI Pipeline 升级 | ZS | 5/12 | ⬜ |
| 🟡 | S0-17 530 新增仓库创建 | ZS | 5/7 | ✅ |
| ⬜ | S1-02 OAG 推理精度测试 | MJD | 5/15 | ⬜ |

**统计**：共 {n} 项 | ✅ {n} | 🔵 {n} | ⬜ {n} | 🟡 {n} | 🔴 {n}
```

**紧急度映射**：

| 看板原始值 | 显示 | 说明 |
|-----------|------|------|
| P0 / 紧急 / 高 | 🔴 | 必须立即处理 |
| P1 / 中 | 🟡 | 重要但不紧急 |
| P2 / 低 | 🟢 | 可延后 |
| 无 / 未标注 | ⬜ | 默认 |

## Deadline 日历提醒模板

```markdown
## 📊 Deadline 日历提醒

| 日期 | 到期任务 | 责任人 | 状态 |
|------|---------|--------|------|
| **{今天 MM/DD}** | {编号} {任务名} | {Owner} | 🔵 |
| {明天 MM/DD} | {编号} {任务名} | {Owner} | ⬜ |
| {后天 MM/DD} | {编号} {任务名} | {Owner} | ⬜ |
| 待排期 | {编号} {任务名} | {Owner} | ⬜ |
```

**规则**：
- 只展示非 ✅ 状态的任务
- 今天到期的行日期加粗
- 未指定 Deadline 的任务归入"待排期"
- 无到期任务时输出"未来 3 天无到期任务"
